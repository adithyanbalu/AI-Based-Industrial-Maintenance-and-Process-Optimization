## 📌 About the Project

An AI-driven industrial analytics project that explores machine operating data, identifies equipment failure patterns, and investigates predictive maintenance techniques to support smarter maintenance decisions and reduce unexpected downtime.

## 🎯 Key Objectives

- 📊 Analyze industrial machine operating data.
- 🔍 Identify patterns associated with machine failures.
- 🧹 Inspect and preprocess the dataset.
- 🤖 Explore machine-learning approaches for predictive maintenance.
- ⚙️ Support proactive maintenance and process optimization.

## 🛠️ Tech Stack

**Python** · **Pandas** · **Matplotlib** · **Scikit-learn** · **Git & GitHub**

## 📂 Dataset

Built around the **AI4I 2020 Predictive Maintenance Dataset**, featuring machine operating parameters such as air temperature, process temperature, rotational speed, torque, and tool wear.
